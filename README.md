## 本地验证

安装Node.js后，在项目根目录执行：

```powershell
npm ci --prefix scripts
npm test --prefix scripts
node scripts/check-miniprogram.js
```

修改`shared/`规则后执行`node scripts/sync-domain.js`，连同生成的部署副本提交；再部署实际受影响的云函数。打开微信开发者工具时使用根目录`project.config.json`。本机`project.private.config.json`不入Git。
