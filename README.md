# 不忍了

微信原生小程序：**模拟点外卖 → 5 分钟冷静期 → 提前不想吃或到时成功 → 累计成果**。  
无真实支付、无真实配送；全程标注为模拟订单。

技术形态：微信原生小程序 + 微信云开发（云函数 / 云数据库 / 云存储）。

## 能做什么

### 首页 · 模拟点餐
- 浏览约 50 家商家、500 道菜品，支持搜索、分类和排序
- 各店独立购物车，订单含菜品快照与 150 分配送费
- 显示热量、约合米饭量，以及按统一口径估算的跑步对照距离
- 提交后进入 5 分钟冷静期（服务端计时，切后台不中断）

### 冷静期 · 忍忍工具
底部导航：**首页 / 忍忍 / 我的**。等待页也可进入同一套工具。

- **不想吃了**：提前成功，奖励与到时成功相同
- **还是吃了**：到期前放弃，不增加成果
- **到时自动成功**：到期优先按自动成功结算
- **电子木鱼**：连击计数、音效震动、随机飘字（健康 / 变瘦 / 变美 / 暴富）
- **心事日记**：文字记录、情绪与陪伴小语；可按住说话转写追加正文
- **图片反转**：把菜图在原色与处理色之间滑动调节
- **激励拼图**：成功推进亮块；可用系统图或自己上传的图片

### 我的 · 成长与记录
- 成就钱包：累计成功订单金额；等级按累计成功次数 0 / 1 / 7 / 21 / 50
- 徽章：首次成功、累计成功、集齐拼图、累计打卡等
- 体重打卡：记录体重即完成当日打卡；目标阶段与 7 / 30 日趋势
- 月历：分别标记打卡与挑战成功
- 资料：昵称与头像；拼图可设为主页背景
- 微光收藏：浏览已完成的纪念卡

### 其他说明
- App 下载 / 提现入口当前显示「未开放」
- 日记正文、体重等私人数据仅本人可见，不写入日志
- 管理员可在小程序内查看埋点看板（需服务端名单授权）

## 目录结构

```text
miniprogram/      小程序端
cloudfunctions/   云函数（业务 + 定时/初始化工具）
shared/domain/    共享业务规则
data/             源数据与本地素材
scripts/          测试与构建检查
deploy/           部署用配置与图库参数
```

## 本地打开与检查

用微信开发者工具打开本仓库根目录（`project.config.json`）。

```powershell
npm ci --prefix scripts
npm test --prefix scripts
node scripts/check-miniprogram.js
```

修改 `shared/` 后执行 `node scripts/sync-domain.js`，再按需部署受影响的云函数。

## 素材说明

- 商家大图原件在本地 `data/assets/shop_pic/`（体积大，不入 Git），需另行拷贝或从云存储同步
- 系统拼图原件在 `data/assets/memorial-presets/`
- 木鱼图片与音效随小程序代码包打包，无需单独上传云存储
