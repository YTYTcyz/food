# 不忍了本地运行手册

> 保留说明：本文件按2026-09-09已确认规则核对，供用户查阅和存档。功能变更以[最终需求基线](最终需求基线.md)为准，实时进度看[实施状态](实施状态.md)；新agent从[项目断点与接续](项目断点与接续.md)进入，无需逐份阅读存档说明。

沿用原文件名供存档，以下步骤适用于当前原生微信小程序工程。

1. 先读《项目断点与接续》《实施状态》，确认已有环境与当前待办。
2. 首次安装本地脚本依赖：在项目根目录执行 `npm ci --prefix scripts`；已有可用依赖可跳过。
3. 微信开发者工具打开根目录 `project.config.json`，使用已配置云环境编译。私人图片双开关仍关闭时，其他主要功能可用。
4. 本地验证执行 `npm test --prefix scripts` 和 `node scripts/check-miniprogram.js`。
5. 修改shared后执行 `node scripts/sync-domain.js`，一起提交生成副本；仅部署实际受影响的云函数。当前函数与配置见《实施状态》。

正常运行不需要执行initDatabase、seed、parse-menu或enrich-menu，不重新建集合、清空测试成果或覆盖基础数据。当前唯一剩余权限协同为《用户协同操作清单》C04第二身份检查，通过后执行C05。

完整功能的用户验收按已部署版本单独交付；《验收清单》提供质量标准，本地通过不等于云端或真机通过。
