# 不忍了产品分析

> 保留说明：本文件按2026-09-09已确认规则核对，供用户查阅和存档。功能变更以[最终需求基线](最终需求基线.md)为准，实时进度看[实施状态](实施状态.md)；新agent从[项目断点与接续](项目断点与接续.md)进入，无需逐份阅读存档说明。

以 [最终需求基线](最终需求基线.md) 为唯一范围。核心是模拟点餐、五分钟冷静期与主动重新选择。

用户可以立即选择不想吃而成功，到时也成功；放弃不计成果。成功后统一计入成就钱包和次数，按 7 次收集拼图。独立手动打卡提供日历记录，体重目标表达个人进展。

首页采用虚拟商家体验，评分月售明确为模拟；无真实交易和可提现承诺。工具中心可以独立使用。首发原生微信小程序与云开发，不另建 NestJS/Prisma/uni-app 工程。
