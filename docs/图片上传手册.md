## 用户图片

拼图接受JPG/PNG，原图不超过10MB，不限长宽比例。超过2048px长边时等比缩小，其余保留尺寸；预览完整照片，不提供会裁掉内容的方形剪裁。原生压缩失败或预览失败可重新选择，不改变原卡片。缩放接口只指定一个边长，使另一边等比计算；相关参数见[腾讯官方图片接口说明](https://intl.cloud.tencent.com/zh/document/product/1219/57745)。头像是独立入口，仍可拖动/缩放裁剪1080方形JPG。

上传流程：选择并处理 → 预览确认 → personal/media.prepare申请带格式的随机私人路径 → 上传显示进度 → media.commit从实际云文件读取格式、大小、方向及宽高 → ready资源绑定卡片。云端不信任客户端上报尺寸。失败保留原卡图，新选图片申请新资源路径。
