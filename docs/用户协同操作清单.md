## C04：剩余的第二微信身份检查

前提：第二身份B有小程序测试权限，实际微信身份与A不同；双端使用同一云环境，私人图片功能开关仍关闭。此前A测试文件已删除，本次必须重新创建一张无隐私图片。

1. **A创建文件**：在小程序调试器中选择无隐私图片，用 `wx.cloud.uploadFile` 上传到 `private/access-check-` 加当前时间戳的唯一JPG/PNG路径。记录实际返回的fileID和使用的cloudPath，先用 `wx.cloud.downloadFile` 确认A可读取；保留文件直到B测试结束。
2. **B读取**：用A记录的同一fileID直接调用 `wx.cloud.downloadFile`，预期因权限拒绝。不要用临时签名URL，也不要以不存在文件、网络故障或环境错误证明权限有效。
3. **B覆盖**：B选择另一张无隐私图片，调用 `wx.cloud.uploadFile`，cloudPath填写A的原路径，预期拒绝；不能换新路径。A再次下载确认原图没有变化。
4. **B删除**：仅对本次无隐私测试fileID调用 `wx.cloud.deleteFile`，预期拒绝；检查返回的 `fileList[].status` 为非0，而不是仅看Promise是否完成。A随后再次读取，确认文件仍在。
5. **公共图片**：A和B分别读取一个实际商家图片fileID和一个系统图库fileID，均应成功。fileID从现有映射与 `deploy/memorial-presets.template.json` 选取。
6. **A清理**：全部核对后由A删除本次测试文件，确认status为0。反馈每项实际结果及权限错误码；任何B访问成功或无法确认原因的失败都先保持开关关闭。

读取与删除调用示例（在各自的小程序身份下执行，替换为本次真实fileID）：

```js
wx.cloud.downloadFile({ fileID: '本次真实fileID' })
  .then(() => console.log('读取成功'))
  .catch(e => console.log('读取失败', e.errMsg));

wx.cloud.deleteFile({ fileList: ['本次真实fileID'] })
  .then(r => console.log('删除检查', r.fileList))
  .catch(e => console.log('删除失败', e.errMsg));
```
