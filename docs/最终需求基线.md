# 不忍了 MVP 最终需求基线

本轮产品核对结论已冻结。本文件优先于所有原始 PRD、设计截图和旧交接资料；实现状态另见《实施状态》。需求已确认不代表功能已开发或云端已部署。

## 技术与数据策略
- 微信原生小程序 + 微信云开发（云函数、云数据库、云存储）；金额以分、体重以克、时间以秒、热量以整数 kcal 保存。
- 底部固定：首页 / 忍忍 / 我的。忍忍是独立工具中心；等待页可进入同一套工具并携带 challengeOrderId。
- 需求调整前没有旧订单；随后产生的新版测试数据已于2026-09-09按用户选择的C00-B实际重置，见0909_1_X完成记录。不实现旧规则兼容或运行时迁移。后续需要保留测试成果时做一次性数据校正；再次全部重置须重新确认范围，清17个业务集合文档和各设备缓存，保留4个基础集合、索引权限和公共素材。重置不是常规业务功能。
- 复用现有 50 家商家、500 个菜品及图片和生成价格；不会因重建业务集合而删除商品素材。
- 内部 userId 关联业务数据，微信身份只用于登录。公共素材公开读取；日记、体重和私人图片仅本人访问。

## 首页与点餐
- 商家与商品名称关键词搜索、分类筛选、综合推荐/评分/月售排序、分页；点击商品进入商家详情并定位商品。
- 商家分类已根据名称生成并复核。评分、月售使用固定模拟数据，不随刷新随机；标签采用招牌推荐、热门套餐等，不表示金额优惠。
- 每店 3 个展示商品，复用现有图片。无个性化推荐、拼音纠错或真实评价发布。
- 保留固定虚拟地址，不编辑联系人、手机号或真实地址。
- 各店分别保留购物车，不能混店结算；提交成功后清除该店本次购物车，其他店保留。
- 不设起送价，不做一键清空或购物车展开面板。订单页仅可增减已选商品；减至零移除，空单不可提交；新商品返回商家页选择。
- 商品价格沿用已生成数据。订单金额 = 商品单价乘数量的合计 + 150 分配送费；无打包费、红包、满减。
- 模拟支付方式保留想瘦币、微信支付、支付宝；仅装饰选项，无真实扣款。
- 菜品继续显示约 N kcal 与约 X.X 碗饭；默认每碗 200 kcal，基准由服务端配置并随订单留版本快照。

## 挑战与时间
- 服务端创建成功即开始 300 秒模拟配送/冷静期，两者使用同一倒计时；不显示另一套 30 分钟配送时间。
- 保留“模拟订单提交成功”弹层，弹层停留时间计入等待。
- 创建仅保存商品/价格/热量快照，不预入账；没有钱包预置态或金额回滚。
- waiting → completed：点击“我已不想吃了，取消订单”立即成功，或到时自动成功；两种成功奖励相同。
- waiting → given_up：到时前服务端确认“还是吃了”才算放弃，不增加成果，不扣减已有等级/徽章。
- 自动成功 completedAt = expiresAt；提前成功 completedAt = 服务端收到操作的时间。晚打开也按实际成功时间归属日期。
- 服务端收到操作时已到期，优先自动成功，不再接受放弃。结算后不被后续操作覆盖。
- 全局同一用户只能有一个等待中挑战。创建时与结算时都在事务中读写同一 user_state 文档保证并发互斥。
- 切 Tab、锁屏、退出均不中断。首期无需定时任务，启动、回前台、查询挑战和新建订单前补结算已到期订单。
- 提交超时先按同一 idempotencyKey 查询，再用原请求重试；不能生成新 key 重复创建。
- 离线选择放入待同步队列，不承诺已成功或已放弃；恢复时若已到期按原到时点成功。只在服务端确认后显示钱包到账。
- 完成状态、钱包流水、统计、拼图、应解锁徽章同一事务提交；失败整体回滚，重试不重复奖励。
- 工具中到时不强制跳页，不丢日记草稿；展示结果或待同步提示。

## 钱包与 App
- 名称“成就钱包”，标注模拟累计节省金额，只累计成功订单金额。提供日期、商家、金额明细。
- 去提现、下载 App、更多健康功能使用统一下载引导，根据来源展示说明。
- 当前没有 App 下载地址；入口显示未开放，不跳空链接。不显示“金额可提现”承诺，提现入口说明功能暂未开放。

## 等级与徽章
- 无独立积分玩法。累计成功达到 0、1、7、21、50 次，对应 Lv.1～Lv.5；展示距下级还差几次。
- 六枚徽章：首次成功、累计成功 7 次、累计成功 21 次、集齐首张拼图、集齐 3 张拼图、累计手动打卡 7 天（不要求连续）。
- 展示未解锁进度，解锁后永久保留。成功次数无每日上限，同一订单只计一次。热量、金额和体重不影响等级。

## 激励卡片 / 微光拼图
- 同一个功能：上方图片拼图，下方体重目标进度、鼓励语、已完成 X/7 次，不再维护第二套激励图片数据。
- 保留图片原始比例，短边6格，长边round(6×长短边比)，上限24格；最多144块，格子允许长方形。总块数N，第k次成功后累计点亮floor(N×k/7)块，每次新增数量最多相差1；位置由服务端从未亮块抽取并保存。
- 按成功次数推进，一天可推进多次；不限制每天一次。
- 无进行中卡片时，成功结算自动创建系统背景卡并推进一次；第七次自动收藏，下一次成功开始新卡；一次成功只归属一张卡。
- 进行中换图保留成功次数；网格相同保留亮块位置，网格改变按新网格和当前成功次数稳定重排（卡ID+网格尺寸），刷新或重复换同图不重抽。不额外计次/发奖，完成锁定图片，可设主页背景。
- 首批系统图库6张JPG/PNG，不限长宽比例，默认card-01；本地data/assets/memorial-presets/v1/保留6张原图；当前环境的真实尺寸/fileID已按0909_3_4配置并回填deploy模板，后续新增图仍须实际上传后记录，禁止猜测。
- 个人拼图JPG/PNG原图不超过10MB，大图按长边2048px等比缩小，小图不放大；保留全图，不强制方形裁剪。头像仍提供独立方形裁剪。
- 系统图片目录 memorial-presets/v1/；公共图库与用户私人图片分开管理。新增图库素材不改变已创建卡片的图片资源。

## 每日打卡与统计
- 手动打卡按北京时间每日一次，本期不补签。成功挑战、记录体重、保存日记不代打卡；打卡不推进拼图。
- 我的月历分别标记已打卡/当天有成功挑战；点击日期查看打卡、成功次数、模拟省钱及体重。
- 连续打卡仅看手动打卡；今日未打卡而昨天连续时显示“截至昨天连续 X 天 · 今日待打卡”。
- 连续挑战成功天数单独命名，同日多次成功算一天，不能与连续打卡混用。
- 累计成果：成功次数、模拟避免热量、钱包金额。周战绩同三项；按实际成功时间和北京时间归属。
- 周一开始，比本周截至当前时刻与上周同期；上期为零展示绝对变化，不显示无意义百分比。无记录不编造战绩。

## 体重与资料
- 首次自动关联身份并直接体验首页；默认头像昵称可改，不强制填写目标。
- 本期不收集身高、不做 BMI 和每日热量预算；不收集性别、具体年龄。
- 我的提供记录今日体重入口，卡片同步更新；一天可记录多次，当前体重取最新，图表按每日最后一条。
- 趋势近 7 天/30 天，无记录日期留空，一条记录仅显示一点。
- 首次设目标固定阶段起始体重；进度 = (起始 - 当前)/(起始 - 目标)，进度条限制 0～100%，真实体重与差值照常显示；分母零不显示百分比。
- 修改目标建立新阶段，以最新体重为新起点，保留旧目标与体重历史。
- 不设置目标仍可使用所有工具/挑战/拼图；不显示虚构体重和进度。

## 工具
- 木鱼：当日累计敲击次数、点击动效、音效开关、震动；无自动敲击和历史页。每日统计持久保存，重新打开不归零，跨日显示新一天。
- 日记：文字上限 2000 字、可选单选情绪；草稿按用户在本机保存，返回提示保留或放弃，草稿不入正式统计。
- 日记保存后：等待页进入则返回等待页，独立进入则回日记列表；支持查看、编辑、删除确认，统计按现存已保存正文重算。
- 停止输入约 1.5 秒选一条对应情绪的固定鼓励语；未选情绪使用通用库，同次编辑不频繁换句，标题“陪伴小语”；不做语音和真实 AI，未来可替换服务适配层。
- 日记保存失败保留内容并可重试，不在日志/埋点暴露正文。
- 图片反转：有挑战时取订单第一项的图片快照；无挑战时提供现有菜品示例，可切换。原图失败可重试或用示例图。
- 左右为原图/处理图；默认 100%，滑杆 0～100%，R'=(1-t)R+tB，B'=(1-t)B+tR，G不变；不覆盖或上传处理图。
- 工具中心独立使用，等待页进入时携带订单关联；轻量展示相同倒计时和返回挑战入口。

## 验收
- 微信小程序首发、竖屏 320～480px，开发者工具和 iOS/Android 各至少一台真机。
- 验收完整确定功能，不能以点单链路跑通宣称整个 MVP 完成。
- 50 店/500 菜品全量核验，搜索/筛选/排序/分页组合不重不漏。
- 固定设备网络，首屏主要内容可操作 ≤2 秒、常规用户接口 ≤3 秒为目标，记录 P95；冷启动单独报告。
- 异常七条、权限隔离、上传进度/失败重试均必测；内部体验后决定发布。
- 不承诺真实支付/提现/识别/语音/真实 AI；不将 1000 并发、99.5% 可用性当本轮已承诺指标。
