# 不忍了用户流程

详细规则：[最终需求基线](最终需求基线.md)。

1. 自动登录 → 首页搜索/分类/排序/翻页 → 商家详情定位商品 → 该店独立购物车。
2. 确认页增减已选商品 → 固定虚拟地址与装饰支付方式 → 商品费加 1.5 元 → 提交。
3. 服务端创建等待订单 → 显示提交成功弹层（此时计时已开始）→ 等待页。
4. 等待页 → 木鱼/日记/反转/激励卡片；工具也能从忍忍独立进入。
5. 不想吃了 → 提前成功；到时 → 自动成功；还是吃了 → 到时前确认放弃。
6. 成功同事务入钱包、累计次数、拼图和徽章 → 结果页 → 我的。
7. 我的手动打卡/月历、记录体重/阶段目标、钱包明细、等级徽章、拼图收藏、主页背景。

退出不中断，离线不确认结果；重新进入补结算，日期归属真实到时点。日记编辑中不强制跳页。无旧规则兼容流程；开发期测试数据处理见《用户协同操作清单》C00。
