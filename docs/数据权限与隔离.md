# 不忍了数据权限与隔离

公共商家、菜品、营养基准和系统图库可读；客户端不直接写入。

用户业务集合统一通过云函数访问，客户端直读直写关闭，云函数从微信身份解析内部userId并校验归属，不信任请求中的userId。不要把服务端创建的数据想当然设为“仅创建者”后就认为内部userId隔离已生效。

私人图片使用私有存储权限及本人授权访问；不可沿用shop_pic公共资源的访问策略。日记正文、体重、私人图片内容不进入日志/埋点。

initDatabase、seed、storageProbe为开发管理工具，只允许管理端调用；开发验收期暂留，正式发布前移除或停用，客户端不得访问。
