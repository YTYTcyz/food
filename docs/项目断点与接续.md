# 项目断点与接续

更新：2026-09-09。目录：`D:/GIT_project/food`。仓库：[YTYTcyz/food](https://github.com/YTYTcyz/food)，分支 `main`。

## 项目目的

“不忍了”是模拟点外卖的小程序：点餐后进入5分钟冷静期，通过木鱼、日记、图片反转和激励拼图陪伴用户。提前不想吃或到时均成功，成功后积累成就钱包、次数和拼图；无真实支付或配送。每日手动打卡与7次成功拼图独立。

## 现在到哪里

主要功能已编码并通过本地自测。云端集合、索引、基础数据、业务函数和6张系统图已配置；完整存储规则及上传者自身读写测试已完成。当前只剩本次权限协同的第二微信身份测试，私人图片双开关保持关闭。完整业务、真实事务、弱网及 iOS/Android 验收尚未完成，尚未发布。
