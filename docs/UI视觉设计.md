# 不忍了 UI 设计

使用已有暖白基底、暖橙点餐、冷静工具、橙粉成果的视觉方向。设计令牌位于 miniprogram/styles/tokens.wxss。

交互与数据以《最终需求基线》为准。旧截图仅参考布局：品牌替换为不忍了；订单无打包费/满减/红包；5分钟唯一倒计时；不想吃了是成功主按钮，还是吃了为放弃；拼图显示7次成功及实际已亮块数/动态总块数，整图等比展示；成就钱包不显示可提现承诺。

我的按用户提供参考图展示头像昵称等级、成果钱包、当前/目标体重与记录今日体重、7/30日趋势、手动打卡月历、拼图收藏、徽章和周同期数据。

激励卡片使用拼图图片、阶段体重进度和X/7次。所有页面包含适用的加载、空、失败重试及待同步反馈；等待结束不得打断编辑。无数据不填假进度。

适配竖屏320～480px；具体实现状态见《实施状态》。

2026-09-08本地页面已补齐：公共样式位于miniprogram/styles/personal.wxss，工具采用四张入口卡片，我的采用成果渐变区与分模块白色卡片。默认头像使用本地文字图形，木鱼为代码绘制外形和原创合成短音效，不依赖系统拼图图片。模板和样式已通过本机微信编译器，实际渲染/音频/图片效果由部署后真机验收确认。

## 核心页面
- 首页：品牌、进行中/成功待查看挑战、搜索、分类、排序、商家评分月售标签、3 个商品缩略图、分页。
- 商家：菜单、kcal/米饭标签、增减、单店购物车金额、去结算；可定位首页点选的商品。
- 订单：固定虚拟地址、已选商品增减、商品费+1.5元、备注、装饰支付方式、提交成功弹层。
- 等待：单一5分钟倒计时、订单摘要、四工具、不想吃了主按钮、还是吃了次级入口、待同步/重试。
- 结果：真实服务端结果、钱包新增、模拟热量、实际等待时间、等级与 X/7 拼图进度。
- 忍忍：四工具主要入口、当前挑战轻量时间/返回路径。
- 我的：昵称头像、等级、累计成果和钱包、体重目标与记录、7/30日趋势、手动打卡月历、拼图收藏、徽章、周同期战绩、设置及未开放App引导。
